## 3. Fonts (self-hosted, two preloads)

**Display: Plus Jakarta Sans Variable, 600–700, `-0.04em`. Text: DM Sans Variable (opsz 9–40), 400/500. Labels: JetBrains Mono Variable, 400/500, uppercase `.12em`.**
Why: it is the Velon ui-kit house pair (`pair-jakarta`), so the landing matches the product family; Jakarta's flat terminals and tall x-height stay crisp and "engineered" at 150 px in pure black on white, where a grotesk like Inter looks generic and a geometric like Outfit looks consumer; DM Sans has optical sizing so 16–18 px body stays open and quiet; the mono carries the OmiCare/kpr "HUD label" voice that makes a monochrome page feel designed rather than unstyled. Files: preload `plus-jakarta-sans-latin-wght-normal.woff2` and `dm-sans-latin-wght-normal.woff2` (≈30 kB each); mono is not preloaded (labels are small, `font-display: swap`). Add `size-adjust`'d local fallbacks (`Arial`/`system-ui`) in `@font-face` overrides so swap causes no shift; split text only after `fontsReady()`.

## 4. Colour (strict monochrome) and texture

`--white #FFFFFF`, `--paper #FAFAFA`, `--black #0A0A0A`, `--ink #18181B`, greys from the ui-kit mono ramp above, `--line rgba(10,10,10,.12)` (on black: `rgba(255,255,255,.14)`). **No colour accent.** The accent is *inversion*: the page alternates white and black bands, the cursor is a difference-blend dot, hovered cards invert. Argued against even a tiny accent: with ten sections of black/white, a single coloured dot becomes the loudest thing on the page and breaks the brief's "strictly". No shadows, no gradients; surfaces divide with 1 px hairlines (`gap: 1px; background: var(--line)` grids).

## 8. Motion rules (smoothness, no jank)

- **Lenis**: `new Lenis({ lerp: 0.1, wheelMultiplier: 1, smoothWheel: true })`, desktop + fine pointer only; drives from `gsap.ticker` (`lenis.raf(t*1000)`), `lagSmoothing(0)`, `lenis.on('scroll', ScrollTrigger.update)`; port applikation `driveLenis()` so the ticker sleeps at rest; `scrollTo` for anchors (`duration 1.2`, default easing). Native scroll on touch — never fake it.
- **Easing/time**: enter = `expo.out` (`.7s` elements, `1.1s` lines); exit = `power3.in` `.45s`; scrubs = `ease:'none'` with `scrub 0.6` (pins) or `0.5` (parallax); hover = `.3–.5s power2.inOut`/`power3.out`; stagger `.06` lines, `.022` chars/words, `.08` cards; nothing longer than `1.3s`; no `elastic`/`bounce` except the single `back.out(1.7)` on the cursor.
- **Transform + opacity only** (plus `background-color/color` on hover, CSS). No `filter/blur`, no `clip-path` animation, no `height/width/top/left` tweens, no `box-shadow`.
- **will-change** only on elements mid-animation: set by GSAP (`force3D: true` globally); SplitText pieces reverted on complete so the DOM returns to plain text; marquee track and cursor are the only persistent `will-change: transform`.
- **No layout thrash**: all measures (`dist()`, pin ends) in functions with `invalidateOnRefresh`; reveals use `gsap.from` once; no `getBoundingClientRect` inside `onUpdate`; counters write `textContent` only.
- **Refresh discipline**: `ScrollTrigger.config({ autoRefreshEvents: 'visibilitychange,load,resize' })`; split and build triggers inside `fontsReady().then(...)`; `ScrollTrigger.refresh()` after fonts and once after the preloader; debounced resize `250ms` → `ctx.revert()` + rebuild only when the breakpoint class changes, else `refresh()`. `anticipatePin: 1` on every pin; pinned sections have fixed `min-height: 100svh` so pinning never reflows.
- **Hidden-before-JS without flash or blank**: `html.js [data-reveal] { visibility: hidden }` (set only when JS runs — six-yards `no-js` flip); the motion module makes them visible via `autoAlpha` as it arms. If the module fails, `.no-js` shows everything.
- **Reduced motion** (`prefers-reduced-motion: reduce` → `html.rm`): nothing split or hidden, no Lenis, no pins (steps stack), counters print final values, marquee static, cursor off, hover fills become instant colour changes. A `data-motion="off"` attribute does the same for testing.

## 10. Performance, accessibility, SEO

- **Budget**: JS ≤ 90 kB gz total (gsap core+ST+SplitText ≈ 45, Lenis ≈ 6, ours ≤ 10); CSS inline ≤ 20 kB; fonts 2 × ≈30 kB preloaded + mono lazy; zero images in the critical path (OG only); no third-party scripts, no analytics tonight.
